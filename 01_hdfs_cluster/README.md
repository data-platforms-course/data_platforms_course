# Практическое задание №1: HDFS-кластер

Здесь будет решение по автоматизированному развёртыванию HDFS-кластера с NameNode, Secondary NameNode и тремя DataNode.

## План развёртывания

1. Установить Java 11 на edge-node, NameNode и три DataNode.
2. Установить Apache Hadoop 3.4.3 на каждый узел.
3. Настроить роли и конфигурацию HDFS.
4. Инициализировать NameNode, запустить сервисы и проверить кластер.

Hadoop 3.4.3 выбран потому, что он совместим с Java 11. Hadoop 3.5.0 требует Java 17 на серверных узлах.

## Структура

- `scripts/` — сценарии установки, настройки, запуска и проверки кластера;
- `config/` — шаблоны конфигурации Hadoop/HDFS;
- `evidence/` — обезличенные результаты проверки работы кластера.

Перед запуском скриптов необходимо скопировать `config/cluster.env.example` в
`config/cluster.env` и указать параметры своей среды. Файл `cluster.env` не
публикуется: он содержит инфраструктурные параметры конкретного стенда.

> Приватные SSH-ключи, пароли, токены и иные секреты в репозиторий не добавляются.
